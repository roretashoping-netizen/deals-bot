# بوت عروض علي إكسبريس على تليجرام

ينشر **٣٠ منتج يوميًا** في قناتك، منشور كل ٣٠ دقيقة تقريبًا من ٩ الصبح لين ١ بالليل بتوقيت الرياض. كل منشور فيه صورة المنتج، وسعره بالريال، والخصم، والتقييم، وعدد الطلبات، ورابط الأفلييت حقك وزر "اطلب الحين".

البوت يختار بس المنتجات اللي تقييمها ٤.٥ وفوق، وعليها ١٠٠ طلب أو أكثر، وخصمها ١٥٪ أو أكثر. وما يكرر أي منتج خلال ٦٠ يوم.

## تجهيز لمرة وحدة (حوالي ٢٠ دقيقة)

### ١) مفتاح API من علي إكسبريس
1. ادخل Portals ثم Tools ثم API، واضغط **Apply Now**.
2. عبّي الطلب، وفي وصف الاستخدام اكتب: Telegram deals channel bot.
3. بعد الموافقة تحصل على **App Key** و **App Secret** من صفحة التطبيق.
4. **Tracking ID**: من Account ثم Tracking ID. إذا ما سويت واحد، اكتب `default`.

### ٢) بوت تليجرام
1. افتح [@BotFather](https://t.me/BotFather) وأرسل `/newbot`، واختر اسم للبوت.
2. انسخ **التوكن** اللي يعطيك إياه.
3. افتح قناتك، واضف البوت **مشرف (Admin)** بصلاحية النشر.
4. اسم القناة يكون بالشكل `@اسم_القناة` (لازم تكون القناة عامة).

### ٣) التشغيل المجاني على GitHub (بدون ما يكون جهازك شغال)
1. سوّ حساب على github.com، ثم مستودع جديد **Private**.
2. ارفع ملفات هذا المجلد كلها، ومعها مجلد `.github`.
3. ادخل Settings ثم Secrets and variables ثم Actions ثم **New repository secret**، وأضف هذي الخمسة:
   `ALI_APP_KEY` و `ALI_APP_SECRET` و `ALI_TRACKING_ID` و `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHANNEL`
4. ادخل Actions ثم AliExpress Telegram Bot ثم **Run workflow** عشان تجربه أول مرة.

بعد كذا يشتغل لحاله كل يوم.

### تشغيل بديل على جهازك أو سيرفر
```
pip install -r requirements.txt
cp .env.example .env      # وعبّي القيم
python bot.py check       # يتأكد إن كل شي مضبوط
python bot.py preview     # يعرض ٥ منشورات بدون نشر
python bot.py run         # يشتغل بشكل دائم
```

## التعديل
كل الإعدادات في `config.json`:
- `posts_per_day`: عدد المنشورات باليوم
- `post_hours`: ساعات النشر. القيمة `[9, 25]` تعني من ٩ الصبح لين ١ بالليل
- `keywords`: الكلمات اللي يبحث فيها عن المنتجات (بالإنجليزي)
- `filters`: أقل تقييم، وأقل عدد طلبات، وأقل خصم

## ملاحظات
- لا ترفع ملف `.env` ولا تشارك التوكن أو الـ Secret مع أحد.
- في البداية لا تنشر روابط القناة بشكل سبام في القروبات، لأن علي إكسبريس يخصم عمولات الزيارات المزعجة (ANTISPAM).
